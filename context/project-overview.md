# Project Overview

**Summary:** Villa Victoria is a vacation rental home in Spain — this project covers everything needed to rent it to guests.

## What this project does

Villa Victoria is our vacation home in Spain. This project contains all work related to renting the villa to guests, including a website, presentations, ad campaigns, automations, and integrations with external management tools.

## Goal

Build everything needed to attract and manage guests for Villa Victoria — a website, presentations, ad campaigns, automations, and any other asset or integration that helps. Two external tools will be connected to help manage the project.
