# Villa Victoria — Additional House Rules

Paste into Airbnb's "Additional rules" field (under House Rules). Written warm but clear — sets expectations without sounding like a lawyer drafted it. All versions verified under Airbnb's ~1000-character limit.

Note: Airbnb already has built-in toggles for the standard rules (smoking allowed, pets allowed, events allowed, suitable for children/infants, etc.) — set those separately. This text is for everything else.

---

## 🇬🇧 English *(659 chars)*

A few extra rules to keep Villa Victoria special for every guest:

• Max occupancy is the number on your booking — no extra guests without prior approval.
• No smoking inside. Outdoors only, ashtrays provided.
• Pool: no diving, no glass near the water, children supervised at all times.
• Sauna: no children unsupervised.
• BBQ: please clean after use and never leave unattended while lit.
• Close doors and windows when AC is on.
• Report any damage right away so we can fix it before the next guests.
• Pets only with prior approval; clean up after them.

Thanks for treating Villa Victoria like your own home — that's exactly what it is while you're here.

• Сообщайте о любых повреждениях сразу — успеем исправить до следующих гостей.
• Питомцы только по согласованию; убирайте за ними.
